# Atlas Workspace UI Review Demo

This is a fictional demonstration package for `frontend-ui-review`. It contains no private project screenshots, real user data, or production assets.

Open `index.html` to try the review flow:

1. Switch between the three demo pages.
2. Add page-specific notes below each image.
3. Choose a review status.
4. Export all notes as Markdown or JSON.

The screens use invented content for demonstration only.
